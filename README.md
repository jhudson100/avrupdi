# avrupdi
Use an AVR microcontroller to program an AVR microcontroller!

Setup
=======

Board assembly information is in the schematics folder.
You will need to flash the backend code to your board.
Might I suggest [PicoUPDI](https://github.com/jhudson100/picoupdi)?

Usage
======

Assuming you have a binary file you want to write called file.bin:

`python avrupdi.pyz write file.bin`
